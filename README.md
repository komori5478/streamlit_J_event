# ⚽ J2/J3 2026 イベントデータ分析アプリ

Streamlit製のサッカーイベントデータ可視化ツールです。J2/J3リーグの2026シーズンデータを多角的に分析できます。

## 機能

| タブ | 内容 |
|------|------|
| 📊 チーム比較 | 得点×xG散布図、レーダーチャート、指標別棒グラフ |
| ⚽ シュート分析 | シュートパターン内訳、xG分布、PA内外比較 |
| 🎯 パス・ポゼッション | 保持率×パス成功率、ゾーン別パス、左右クロス比較 |
| 🏃 選手分析 | ゴール×アシスト散布図、選手ランキング |
| 📈 時系列トレンド | 節別累積推移、ヒートマップ |

## セットアップ

### ローカル実行
```bash
pip install -r requirements.txt
streamlit run app.py
```

### データについて
サイドバーからXLSXファイルをアップロードしてください。  
以下のシートが含まれるファイルに対応しています：
- `全試合データ_チーム`
- `全試合データ_選手`

## Streamlit Cloudへのデプロイ

1. このリポジトリをGitHubにpush
2. [share.streamlit.io](https://share.streamlit.io) にアクセス
3. リポジトリを連携して `app.py` を指定
4. Deploy！
